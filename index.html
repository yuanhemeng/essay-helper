3.3 Retrieval-augmented Generation

In this section, we describe our approach to retrieval-augmented generation (RAG). RAG combines a pre-trained parametric memory with a non-parametric memory, which is indexed by a dense vector index of Wikipedia.

Our model can be viewed as a general-purpose fine-tuning recipe for knowledge-intensive NLP tasks. The retriever provides access to explicit knowledge, while the generator produces a fluent response conditioned on the retrieved passages.

pRAG(y | x) = ∑z pη(z | x) pθ(y | x, z)

We use a pre-trained sequence-to-sequence transformer as the generator and a neural retriever trained jointly with the generator. This design allows the model to update its knowledge without expensive re-training of all parameters.

The retrieval component searches a large external memory for passages relevant to the input. We consider the top-k passages and marginalize over them during generation.

This formulation has two practical advantages. First, the external memory can be updated independently. Second, the model can cite evidence for its predictions.

The generator is trained to condition on both the original input and the retrieved documents. During inference, the retriever and generator work together in an iterative pipeline.

We find that this combination yields strong performance across open-domain question answering and fact verification.
